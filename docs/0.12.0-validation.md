## 实现范围

共享根配置通过 includes 显式加载模块 TOML，仅接受 projects/services/auth/cases 及对应 environment 覆盖。共享重复实体拒绝静默覆盖；本机覆盖、environment 顺序、数组替换和相对路径含义保持不变。没有递归 include、目录扫描、私有 include 或业务项目迁移。

workspace check 返回配置文件归属与 Git 检查，cases show 返回配置来源链；两者不打印整份配置或秘密值。缺失、非法、私有、忽略、越界、重复、嵌套仓库和子模块引用在业务执行前拒绝。Git 不可用和共享文件未跟踪返回未验证，正常加载不单凭这些情况被阻止。
