# 0.15.0 磁盘回收验证

本文记录 0.15.0 发布前的实现与安装包验证，发行内容包括资源用量和磁盘回收。发布通过 `v0.15.0` 标签触发，可安装状态以官方 PyPI 发行结果为准。验证开始时官方 PyPI 最新为 0.14.0，0.15.0 未占用；验证没有修改正式安装入口或业务项目。

## 实现范围

- `resources disk [--all]`、`resources clean` 预览、`resources clean --apply PLAN_ID [--unit UNIT_ID]`，以及本地 `resources keep UNIT_ID [--remove]`。支持根目录筛选、分页、JSON、扫描条目／耗时预算。
- 根配置和本机覆盖声明临时目录，模块 include 不接受 storage；共享路径相对工作区，本机绝对路径及个人保留偏好保持私有。Kit 运行／会话按登记归属与 environment 应用保留规则，重复声明缓存合并所有保护条件。
- 预览冻结配置摘要和文件身份，执行重新核对；写入持共享占用、回收持独占占用。活跃操作、待清理状态、仍使用的服务日志／产物、保留标记、Git 跟踪及不明归属受到保护。失效占用解除不等于业务清理成功。
- 不跟随链接或 junction，不回收硬链接文件，不递归清空根目录。Linux 使用目录描述符和叶节点身份核验；Windows 使用不共享写入／删除的父目录句柄与按句柄删除，并将 NTFS ChangeTime 与大小、mtime、文件身份一起复核。元数据检查不承诺识别外部程序隐藏的所有变更。
- 只删除计划中的文件及已空目录，扫描后新增内容保留。单次计划不能重试；部分失败／中断保留回执和逐文件结果，重新预览剩余内容。
- 保留 run.json、简短 HTML 报告、会话摘要及小型回收记录；历史结论保持原样，展示附件回收状态。已回收观察的 read_reply 拒绝返回过期成功图片。业务 runs cleanup 和磁盘回收相互独立。

## 验证证据

所有数据来自临时工作区及独立 ECHO_KIT_DATA_HOME。没有扫描或删除截图中的业务目录，没有清理 Docker 镜像或业务容器，也没有修改业务项目配置。

- Windows / Python 3.12.6 存储、文件接口和随包指南最终专项：**51 passed**。
- 最终 Windows 核心回归：**393 passed、20 skipped**；最终 wheel 在 Linux / Python 3.12 的完整核心回归：**397 passed、16 skipped**。跳过项为平台条件或需要显式开启的真实集成测试，不计为已验证。
- 首次发布 CI 的 Windows 时间戳恢复测试暴露文件系统时间粒度假设：极快的连续写入可落在同一刻度。测试改为通过独立探针确认文件系统时钟已推进，再写入并验证保护；不增加生产等待、不修改删除检查，也不依赖固定睡眠断言。
- 覆盖默认／自定义运行目录、中文空格路径、仓库外私有缓存、旧证据、重复与重叠根、environment 范围及保留覆盖、最近份数、保留标记、Git 跟踪、硬链接和真实 Windows junction。
- 用同步信号验证真实 apply 持有独占占用期间，新观察／写入被阻止；活跃写入期间清理跳过。验证预览后修改、目录替换、修改后恢复 mtime、删除期间新到内容均不会扩大删除清单。
- 验证原始 verdict／run.json 不变、原 HTML 报告标注回收、旧观察回执拒绝过期图片、权限失败、部分删除、中断、已不存在、篡改计划及重复执行。仅删除清单中的冻结文件，并保留处理记录。
- 以 250 个小文件和 4 MiB 受控文件检查计数与体积，不制造几十 GiB 垃圾。扫描上限／时间不足的根不会生成候选，扫描不读取归档正文。
- 源码目录之外的独立 Windows 环境安装 wheel，实际执行磁盘账单、全局发现、保留／取消、预览与执行、历史查看／报告、三个精简指南、resources 主题、完整读取、更新说明与导出。import 指向 site-packages；已有导出修改仍拒绝覆盖。
- 三个 Skill 头字段、15 份当前 Markdown 的 145 个本地链接与锚点有效，公开协议和随包副本逐字节一致。全局查询不需要当前目录有工作区配置。

Windows 本地验证 wheel 的 SHA-256 记录在下述 package.json；官方发行文件以 PyPI 提供的摘要为准。wheel 包含四个 storage 模块和完整随包文档，不包含临时验证文件或 pyc。

最终核心回归及安装包摘要记录在本机忽略目录 `.echo-kit/validation-storage-0.15.0/`：windows-core-final.xml、windows-storage-final.xml、linux-core-final.xml、package.json、links.json。Linux 验证使用关闭网络、源码只读挂载的专用临时容器；wheel 正常安装到独立环境，不依赖源码路径或 PYTHONPATH。早期测试支架仅用 PYTHONPATH 安装，导致隔离导入和旧入口迁移测试找不到正式入口；改为真实独立安装后重新验证。

## 限制

资源协调保护正确登记的新 Kit 操作，不保证阻止任意外部程序写文件或识别远端任务。归属、Git 或边界无法核验时跳过；旧产物不会仅凭目录名认领。逻辑删除字节与磁盘空闲变化分开报告，不承诺释放同等物理空间。

本轮不涉及浏览器运行逻辑或托盘界面修改；未重跑真实 Chromium／业务集成和人工桌面验收。Linux 文件行为在专用容器中验证，不冒充另一台物理主机；macOS、网络共享盘和其他 Windows 文件系统未验证。安装包与导出的规则待正式发布后才能到达其他已安装用户；本轮不覆盖他们的项目副本。
