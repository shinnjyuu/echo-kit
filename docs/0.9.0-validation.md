## 实现与兼容

- cases list/show 复用合并后的 cases 配置，提供逻辑分类、关键词检索和选中说明读取；不维护第二份注册表。
- guide 默认返回精简 Skill、核心规则、主题目录和发行说明；--topic 按需展开，--full 保留完整协议与参考资料。skills show 只读取 Skill，不自动附带身份准备正文；参考资料仍可通过 auth 主题、完整模式和导出获取。
- runs list 从完整记录数组变为 items/total/limit/offset/next_offset 对象，默认最近 20 条摘要。完整记录仍通过 runs show 获取。调用方需要适配此 JSON 变化。
- case 文档只读共享路径；本机覆盖不能绕过检查。Git 不可用／非 Git 工作区不能确认忽略状态时阻止正文读取；目录查询和未配置 docs 的旧用例仍可使用。
- 运行保护不依赖分页；未完成状态与原有执行流程未修改。坏历史记录给出有限诊断，不输出解析异常中的原文。
