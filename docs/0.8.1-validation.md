# 0.8.1 无窗口启动修复

问题：Windows uv/venv 的 python.exe 重定向启动链中，原托盘的 DETACHED_PROCESS 未阻止底层解释器创建控制台。现场确认旧托盘及 conhost 子进程，路径与用户截图一致。

改动：使用同一环境的 pythonw.exe，使用 CREATE_NO_WINDOW 和原有进程组、Job breakaway 标志，不再组合 DETACHED_PROCESS。缺少同环境 pythonw 时明确失败，不换解释器或静默回退到有窗口模式。

验证：Windows tray/documentation 回归 31 passed。新增回归通过真实 venv 启动链执行探针，GetConsoleWindow 为零，sys.prefix 和包版本保持一致；缺少 pythonw 的失败路径也已覆盖。wheel 构建并安装到仓库外独立环境。

现场旧 0.8.0 托盘未响应正常退出请求，核对其进程身份和 echo_kit.tray 命令后，仅终止该 UI 进程，未终止业务进程树。替换为本轮安装包启动的 0.8.1 托盘；检查 GUI 启动器为 pythonw，新托盘无控制台子进程。原六个服务和浏览器容器仍运行。未操作 Windows Terminal 整个应用，也未修改业务配置。

原生桌面的图标、窗口视觉效果未通过工具直接观察；以上为进程与控制台探针证据。当前托盘使用本轮独立安装包，全局安装未修改。修复待提交和发版；普通自动升级要等新包正式发布。
