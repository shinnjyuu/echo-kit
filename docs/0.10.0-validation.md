## 实现

- 显式 resource_id 对应同一用户数据目录中的统一服务实例。无 ID 时按工作区、环境和名称区分。工作区文件只保存引用，统一登记保存进程身份、实例代次、启动来源、引用、依赖和证据位置。
- 启动锁串行化同一身份的首次启动；启动输入不相容、活进程不健康或身份不确定时拒绝自动替换。只读状态不迁移旧登记；原工作区显式启动可核验、备份后采用原进程。
- Verify 从准备占用原子转为共享使用；service_access=exclusive 保留独占。嵌套启动不降级外层独占。停止与重启检查活动占用和统一登记中的依赖；无参数仅选本工作区／环境启动的实例。
- 新报告记录实例代次和使用方式。清理检查原资源、实例代次及启动／清理配置摘要，拒绝配置变化导致的目标转移。停止无法确认时保留待人工核查的占用。
- 启动输入和进程命令使用本机私钥 HMAC 比较；Windows 密钥用 DPAPI 保护，Unix 密钥文件权限为 0600。统一登记不保存配置秘密明文。既有日志和旧迁移备份仍是本地证据，不是可直接公开的材料。
- 托盘统一服务按实例去重，浏览器仍按工作区展示。托盘协议升为 2，旧 UI 需要用户明确 tray stop/start；不会自动替换旧进程或重启业务资源。
