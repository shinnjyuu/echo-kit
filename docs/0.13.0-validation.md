## Windows 桌面与 Docker

显式启用集成测试后，`tests/test_docker_emergency.py`、`tests/test_windows_emergency_tray.py` 和 `tests/test_docker_browser.py` 共 6 项通过。

- 原生 Windows 托盘进程在测试启动方退出后仍存活。测试调用真实菜单项的回调，受管服务退出，结果通知显示已停止 1 项、未确认 0 项。未进行鼠标点击验收，也未模拟系统内存耗尽。
- 本机 Docker Engine 中，已登记的暂停容器和自动重启中的容器均被急停，未登记容器继续运行。实际 Playwright 托管浏览器可在急停后使用 `browser up` 重新启动原容器。测试容器由各自的测试清理。

急停依赖本地登记和归属核验。无法核实的启动或退出按未确认报告。已脱离登记进程树的进程和远端业务任务需要单独核验。升级本机安装后重启托盘可载入新菜单。
