## 改动

## 静态场景核对

以下为指南内容核对，不代表已对各类 Agent 宿主完成行为实测。

| 场景 | 指引结果 |
| --- | --- |
| 新增页面入口、布局调整、展开详情、状态提示变化 | 主动选择少量清晰的最终页面截图，每张解释位置、变化与用法 |
| 后端修改引起页面变化 | 按用户可见结果选择截图，不按修改的代码目录判断 |
| 纯后端修改 | 文字说明行为与验证结果，不默认制图 |
| 用户自行验收 | 保持人工验收，不为截图强制增加完整浏览器实验 |
| 页面、认证或交互工具不可用 | 说明截图未取得原因、可用业务入口和待确认事项，不虚构截图或成功结果 |
| 隔离验收页、模拟数据、受控状态 | 明确标注来源，页面展示与真实业务验证分开说明 |
| 刷新恢复、取消、计时等行为 | 单独列出实际执行的检查；截图本身不能证明行为正确 |
