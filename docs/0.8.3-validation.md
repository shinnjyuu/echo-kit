## 文档场景核对

| 场景 | 指南要求 |
| --- | --- |
| 无需登录 | 跳过身份准备，不为匿名实验生成脚本。 |
| 已有可用身份 | 核对归属、角色和租户后复用，再验证登录及最小业务权限。 |
| 缺少准备入口 | 优先检查种子、夹具和正常管理入口，再编写项目脚本；写好不等于已验证。 |
| 密码、角色或租户不符 | 报告冲突，不接管同名账号、不重置密码、不扩权。 |
| 共享目标授权不足 | 可准备代码和说明，不能据指南推定写入授权。 |
| 临时账号清理失败 | 保留本次准确 ID、目标和归属证据，不删除复用身份。 |

以上为维护者对指令的场景核对，不宣称在真实业务项目中创建、登录或清理过账号。伪代码中的函数是项目占位逻辑，不是可直接执行的 Kit API。
