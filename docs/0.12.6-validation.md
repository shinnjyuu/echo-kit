## 验证结果

- Windows 相关核心测试：`uv run pytest tests/test_runtime_debugging.py tests/test_documentation.py -q`，17 passed、2 skipped（显式真实调试测试）。
- Windows 真实调试：`ECHO_KIT_DEBUG_TESTS=1`，`uv run --with debugpy --with websocket-client pytest tests/test_runtime_debugging.py -q` 在加入受控边界测试前运行，3 passed。debugpy/websocket-client 仅装入 uv 临时依赖环境。
- Python：真实 DAP adapter 连接、断点命中、调用栈与指定变量读取、单步、清除断点、继续、退出事件和断开；观察到 amount=threshold=10 而 accepted=False。首次测试驱动错误是假设 initialized 事件总有 body，修正后通过，另核对无该次遗留 fixture 子进程。
- Node 24.19.0：正常运行产生 input/input/parsed/end 的关联事件及单调耗时；独立 Inspector 连接命中分支，读取变量、单步、清除断点、继续和断开。暂停运行的时间不用于性能结论。
- 受控演练覆盖依赖资源独占冲突、模拟实例变更、连接失败、中断和恢复不确定；无自动重试，其他操作记录不变，收尾不确定保留占用。这是现有 operation 语义验证，不是新接入所有调试器的统一管理功能。
- 模拟秘密未出现在正常 fixture 输出中；真实调试测试只读取指定变量，不请求完整作用域，不保存完整协议流。
- wheel/sdist 构建成功；三个 Skill 校验通过，协议副本一致，本地文档链接检查通过。
- 仓库外安装 wheel：三个指南各五种模式，共 15 种读取组合通过；更新说明、完整资源导出及已有导出拒绝覆盖通过。
