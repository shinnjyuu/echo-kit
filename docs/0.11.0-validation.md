## 范围

新增 `docs map/context/read` 和 `docs check --rules`，发现范围为整个选定工作区，包含根目录与各模块原位置的规则文件，不限于 `echo/`。没有搬迁业务文档，也没有自动创建各级规则文件。

验证覆盖规则链与兄弟目录隔离、中文与空格路径、分页、500 个候选限制、64 KiB 正文限制、续读、直接引用、私有和忽略文件隔离、嵌套仓库与子模块、符号链接、非标准规则名称、Git 不可用，以及查询不执行文档命令。目录结构检查不代表业务规则语义正确。
