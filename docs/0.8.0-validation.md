## Windows 实际后台进程

使用独立临时工作区和受管测试进程，安装包成功创建真实 pystray 图标进程并完成 visible/ready 握手。启动它的父 Python 进程退出后，托盘和测试进程仍存活。tray stop 后托盘退出，测试进程继续运行；随后只清理本轮创建的测试进程。
